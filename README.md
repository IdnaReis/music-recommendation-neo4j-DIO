# 🎵 Music Recommendation com Grafos - Neo4j

## 📌 Sobre o Projeto
Sistema de recomendação de músicas baseado em grafos usando Neo4j.
O algoritmo recomenda músicas com base nos gêneros que o usuário curtiu.

## 🗂️ Modelo do Grafo
- *Nodes:* Usuario, Musica, Artista, Genero
- *Relacionamentos:* CURTIU, FEITA_POR, PERTENCE_A

## 🚀 Como executar
1. Instale o Neo4j Desktop
2. Crie uma instância local
3. Execute os scripts da pasta /queries

## 🛠️ Tecnologias
- Neo4j Desktop 2.1.3
- Cypher Query Language
